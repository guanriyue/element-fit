# Lab

The Lab provides browser pages for observing measurement behavior while many components render together or while content and container width change. It also preserves alternative implementations that have not become public components. These pages are not introductory examples, and their results are not fixed performance benchmarks.

Each component page can adjust the number of rendered instances. Pages with a comparable baseline can also switch between the component and the baseline implementation. The FPS indicator in the upper-right corner helps observe frame-rate changes during interaction.

## Experimental implementations

[OverflowList DOM Scheduling Experiment](./overflow-list-dom) uses a layout algorithm similar to the public component but controls Items and Accessories through direct DOM writes. It exists only to compare the performance and constraints of different commit mechanisms and is not part of the public API.
