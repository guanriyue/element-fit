# LineClamp

`LineClamp` 用于限制 inline 内容的可见行数，并在内容确实超过限制时渲染 suffix。组件只负责截断、overflow 测量和 suffix 布局；展开状态、按钮样式和交互行为由调用方控制。

## 导入

```tsx
import { LineClamp } from '@guanriyue/react-fit/line-clamp';
```

## 基础用法

`expanded` 是受控状态。修改 `expanded` 只改变当前视觉展示，不会改变 `lines` 这个测量基准。

## Overflow 状态

`onOverflowChange` 会在首次可信测量完成后触发，并在测得的 overflow 状态变化时再次触发。这里的 overflow 表示内容超过 `lines` 基准，不表示展开后的当前 UI 正在被裁切。组件会监听内容变化，下面的示例可以通过 textarea 输入或一键切换长短文本来观察重新测量。

## Inline 内容

`LineClamp` 接收 `children`，因此可以承载文本、链接、强调、`code`、`inline-block` 和 `<br />` 等 inline 内容。复杂 inline box、强制换行和不同浏览器的 Range rect 可能带来边界差异。

## 测量策略

默认策略是 `in-place`，它直接读取当前 DOM 的行信息，不创建额外测量节点。`clone` 会临时克隆正文内容到隔离 DOM 中重新排版，代价是额外布局，但可以避开部分可见 suffix 对测量的干扰。

## Suffix 形态

收起状态下 suffix 会通过 float 布局放到最后一个可见行附近。它可以是提示、详情、跳转或展开入口，不必总是控制 `expanded`；也可以把提示和展开控制组合在同一个按钮上。suffix 应该保持紧凑，建议高度不超过一行；较长或较高的 suffix 会参与最后一行排版，可能挤压正文。


## 布局要点

- `lines` 不是正整数时，会禁用截断、overflow 测量和 suffix 渲染。
- suffix 仅在测量结果为 overflow 时渲染。
- 收起状态下 suffix 使用 float 影响最后一行布局；展开状态下 suffix 回到正文之后的普通 inline 位置。
- 组件会监听内容变化，并在正文文本或子节点变化后重新测量；Root content box width 或 `lines` 变化时也会重新测量。
- `in-place` 当前只识别 `<br />` 形成的 hard line break；其他 CSS 或文本规则形成的强制换行可能需要改用 `clone` 或自定义方案。
