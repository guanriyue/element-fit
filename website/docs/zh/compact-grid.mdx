# CompactGrid

`CompactGrid` 使用和 `FitGrid` 相同的自适应网格逻辑，但额外提供了 `Extra` 和 `ExtraSlot`。

当默认布局还有空间时，`Extra` 会作为独立网格项渲染；当普通网格项刚好填满当前行时，`Extra` 会移动到最后一个普通网格项中的 `ExtraSlot`，避免额外内容单独掉到新的一行。

## 跨列 Item

`CompactGrid.Item` 可以通过 `colSpan` 声明当前项需要跨越的列数。传入数字时会跨指定列数，传入 `'full'` 时会占满整行。
