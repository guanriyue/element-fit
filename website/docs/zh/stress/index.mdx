# 压力测试

这些页面用于在浏览器中人工观察大量组件同时渲染、内容变化和容器宽度变化时的测量性能。它们不是功能用法示例，也不代表固定的性能基准。

每个组件页面都可以调整渲染数量；具备可比基础实现的页面还可以在组件与基础渲染之间切换。页面右上角的 FPS 指示器用于辅助观察交互期间的帧率变化。

## 独立组件

- [CompactGrid](./compact-grid)
- [FitSwitch](./fit-switch)
- [OverflowList](./overflow-list)
- [OverflowList DOM（实验）](./overflow-list-dom)
- [InlineOverflow](./inline-overflow)
- [LineClamp](./line-clamp)

## 综合场景

[综合业务场景](./real-world) 将多个自适应组件放入卡片、表格和详情面板中，用于观察更接近业务页面的混合布局。
