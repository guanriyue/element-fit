# 实验室

实验室用于在浏览器中观察大量组件同时渲染、内容变化和容器宽度变化时的测量表现，也用于保存尚未成为公共组件的替代实现。这里的页面不是功能入门示例，观察结果也不代表固定的性能基准。

每个组件页面都可以调整渲染数量；具备可比基础实现的页面还可以在组件与基础渲染之间切换。页面右上角的 FPS 指示器用于辅助观察交互期间的帧率变化。
