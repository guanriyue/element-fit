# 组件指南

这里集中展示 Element Fit 组件的使用方式与可交互示例。每个页面都提供针对容器宽度、内容变化和条件渲染等场景的观测控制。

- [FitGrid](./fit-grid)：使用 CSS Grid 根据可用空间自适应列数。
- [CompactGrid](./compact-grid)：根据容器宽度调整网格布局。
- [FitSwitch](./fit-switch)：在多套内容方案之间选择能够容纳的布局。
- [InlineOverflow](./inline-overflow)：观测单行 inline 内容的溢出状态。
- [LineClamp](./line-clamp)：限制内容行数并响应溢出变化。
- [Textarea](./textarea)：根据内容自动调整文本输入区域高度。
