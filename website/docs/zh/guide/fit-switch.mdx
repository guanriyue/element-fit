# FitSwitch

`FitSwitch` 用来声明两套完整视图：`Collapsed` 和 `Expanded`。它会测量 `Expanded` 视图需要的宽度，并使用两个视图共同的父元素作为可用宽度容器。

当 `Expanded` 能放下时，显示完整视图；当放不下时，切换到 `Collapsed` 视图。

组件不会为两个 view 注入展示或布局样式，只在当前未选中的 view 上添加空值的 `data-fit-inactive` attribute；当前展示的 view 不带该 attribute。调用方需要让 inactive view 脱离常规流并在视觉上隐藏它，通常可以根据 dataset 设置 `position: absolute` 与 `opacity: 0`。不要使用 `display: none`，否则组件无法继续测量 Expanded 的宽度。

当当前展示的 Expanded 因内容、字体或样式令其观测宽度发生变化而放不下时，它会在切换为 inactive 的同时短暂获得 `data-fit-invalidated` attribute。它会至少保留一个绘制帧，调用方可通过 `data-fit-invalidated:transition-none` 关闭新版 Expanded 的退出动画，同时保留 Collapsed 的进入动画。Collapsed 切换到 Expanded 以及 Container 宽度变化不会添加该 attribute，因此仍可保留正常的双向切换动画。

## 裁切切换动画

两个 view 会始终保持挂载，并通过 `data-fit-inactive` 标记当前 inactive view。下面的工具栏让共同 parent 右对齐并设置 `overflow: hidden`：Expanded 在 inactive 状态下向右移动自身宽度，attribute 被移除时从右向左划入；反向切换时则向右划出。Collapsed 使用相同的状态旋转并显示齿轮按钮。当前展示的 Expanded 因自身尺寸变化切换为 Collapsed 时，`data-fit-invalidated:transition-none` 会跳过已经失效的 Expanded 退出动画，并保留 Collapsed 的进入动画。

示例没有降低 Expanded 的 opacity，而是通过 Tailwind 状态变体在 inactive 状态下设置 `position: absolute` 和 `translate-x-full`，使它完全依靠 transform 和父容器裁切隐藏。transform 不改变 ResizeObserver 读取的 border-box width，因此不会干扰 FitSwitch 的宽度判定。
