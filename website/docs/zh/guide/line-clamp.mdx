# LineClamp

`LineClamp` 用于限制 inline 内容的可见行数，并在内容确实超过限制时渲染 suffix。组件只负责截断、overflow 测量和 suffix 布局；展开状态、按钮样式和交互行为由调用方控制。

## 导入

```tsx
import { LineClamp } from '@guanriyue/react-fit/line-clamp';
```

## 基础用法

`expanded` 是受控状态。修改 `expanded` 只改变当前视觉展示，不会改变 `lines` 这个测量基准。下面的示例可以调整容器宽度和行数，并切换 clamp 与 expanded 状态，直接观察 `collapsed`、`expanded` 和 `unclamped`。

## 样式控制与 data-state

Root 渲染为 `div`。组件不设置常态下的 `display`、`word-break`、`overflow-wrap` 或 `white-space`，正文的
换行规则和视觉样式由开发者通过 `className`、`style` 或继承样式控制。下面同时挂载普通换行与
`word-break: break-all` 两组实例，并通过 `data-[state=...]` 属性选择器为收起和展开状态设置不同颜色。
两组实例共享宽度、行数和 expanded 状态，只有换行策略不同。

```tsx file="<root>/src/demos/line-clamp/style-control.tsx" preview

```

Root 的 `data-state` 有三个值：

- `collapsed`：`lines` 是正整数，并且 `expanded={false}`。
- `expanded`：`lines` 是正整数，并且 `expanded={true}`。
- `unclamped`：`lines` 缺省或不是正整数，此时截断、overflow 测量和 suffix 均被禁用。

收起状态下，组件仍会设置实现核心截断所需的 `display: -webkit-box`、`-webkit-box-orient: vertical`、
`overflow: hidden` 和动态 `-webkit-line-clamp`。内部 Spacer 与 Suffix 的 float 样式也属于末行 suffix
布局的一部分。Root 的 `style` 最后合并，因此可以覆盖这些属性，但覆盖后需要由开发者自行保证截断与
测量语义一致。

## Suffix 形态

收起状态下 suffix 会通过 float 布局放到最后一个可见行附近。它可以是提示、详情、跳转或展开入口，不必总是控制 `expanded`；也可以把提示和展开控制组合在同一个按钮上。示例可以切换长短 suffix，观察它对最后一行正文空间的影响。suffix 应该保持紧凑，建议高度不超过一行；较长或较高的 suffix 会参与最后一行排版，可能挤压正文。

## 布局要点

- `lines` 不是正整数时，会禁用截断、overflow 测量和 suffix 渲染。
- suffix 仅在测量结果为 overflow 时渲染。
- 收起状态下 suffix 使用 float 影响最后一行布局；展开状态下 suffix 回到正文之后的普通 inline 位置。
- 组件会监听内容变化，并在正文文本或子节点变化后重新测量；Root content box width 或 `lines` 变化时也会重新测量。
- MutationObserver 不监听 attributes。仅修改 class、style、继承样式、字体或外部样式表时，如果 Root content box width 没有变化，也没有正文 DOM mutation，不保证重新测量。
- `in-place` 当前只识别 `<br />` 形成的 hard line break；其他 CSS 或文本规则形成的强制换行可能需要改用 `clone` 或自定义方案。
